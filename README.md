Chart Flow
Generate structured flowcharts for Java methods.
Place your cursor inside a Java method, right-click and select "Generate Code Flowchart".
The flowchart renders in the Chart Flow tool window on the right side.
Features:
Render structured flowchart for Java method, support if/else, for/while/do-while, switch, try-catch-finally, synchronized, return, throw.
Merge sequential statements into block nodes; highlight method invocations as call nodes.
Smooth bezier connections, theme-aware rendering for Light/Dark/HighContrast UI.
Pan, zoom, fit-to-window, hover tooltip.
Export to Mermaid diagram or PNG image.
Call chain analysis: upstream callers and downstream callees.
Export call chain & redundancy analysis as plain text for AI analysis.
Variable lifecycle tracking for object reference and parameters.
Compatibility: IntelliJ IDEA 2025.3+.
